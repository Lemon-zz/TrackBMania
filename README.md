**TrackBmania** is a free, open-source trackball project.

## Overview

Basically i made it myself, as i find no commercial alternatives - i had Kensington and find it a little discomfy - so i made one for me.

As controller i use ESP32-S3 - it have built-in USB for programming and work, along with wireless capacbility.

And i want it to have smooth scroll - and i made it. Now i scroll not by 3 rows, but pixel-by-pixel.
